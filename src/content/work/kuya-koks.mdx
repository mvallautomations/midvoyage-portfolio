# Kuya Kok's Griddle & Grill

**Digital transformation for a family-owned Filipino restaurant.**

This case study outlines the approach for building a mobile-first online presence using Next.js 15, optimized for local search and quick access to the menu and location details.

## Strategy
We focused on performance and mobile usability, given that 90% of local restaurant searches occur on mobile devices.

## Outcomes
- **Custom Domain Setup**
- **Mobile-first Design**
- **Seamless CMS Integration (upcoming)**
